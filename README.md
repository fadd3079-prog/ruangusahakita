﻿# Ruang Usaha Kita

Ruang Usaha Kita adalah marketplace jasa digital yang menghubungkan UMKM dengan content creator untuk kebutuhan promosi digital.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- shadcn/ui

## Core Flow

Beranda → Katalog Kreator → Detail Paket Jasa → Keranjang → Checkout Brief → Pembayaran → Status Pesanan → Dashboard
