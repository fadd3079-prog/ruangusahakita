# Roadmap

This roadmap is intentionally conservative. Ruang Usaha Kita is maintained as an early-stage marketplace MVP, so roadmap items are framed around reliability, contributor usability, and domain integrity rather than aggressive feature claims.

## Near Term

- Strengthen repository documentation and maintainer workflow
- Expand test coverage around auth, order flow, payment sandbox, delivery, and revision logic
- Improve contributor onboarding for Supabase setup and local verification
- Continue performance review for catalog, dashboards, and image-heavy routes
- Review RLS and private file access assumptions

## Mid Term

- Improve dashboard data confidence and analytics presentation
- Reduce operational friction around local seed data and admin setup
- Harden storage, delivery file access, and revision traceability
- Improve accessibility and mobile QA coverage
- Add more repository automation where it does not require privileged secrets

## Longer Term

- Prepare a more structured release cadence
- Expand architecture documentation around scaling constraints
- Improve admin moderation and observability tooling
- Improve contributor testing ergonomics
- Evaluate production-readiness gaps without overstating deployment maturity
